Школа Госуслуг — обновление YouTube-видео

Что добавлено:
1. В админке теперь можно вставлять обычную ссылку YouTube:
   - https://youtu.be/...
   - https://www.youtube.com/watch?v=...
   - https://youtube.com/shorts/...
   - https://www.youtube.com/embed/...

2. Сайт автоматически превращает ссылку в встроенное видео.
   Ученик смотрит урок прямо на сайте, без обязательного перехода в YouTube.

3. Также добавлена поддержка Rutube-ссылок вида:
   - https://rutube.ru/video/...
   - https://rutube.ru/play/embed/...

4. Для Supabase Free добавлена понятная проверка: если видеофайл больше 50 МБ,
   сайт сразу подскажет загрузить видео на YouTube и вставить ссылку.

Как пользоваться:
1. Загрузите видео на YouTube.
2. Выберите доступ «Доступ по ссылке».
3. Скопируйте ссылку.
4. Откройте админку сайта → Уроки → Редактировать урок.
5. Вставьте ссылку в поле «Ссылка на видео».
6. Нажмите «Сохранить урок».

Supabase менять не нужно.
OPTIMIZE_SUPABASE.sql заново выполнять не обязательно, если вы уже выполняли его раньше.

Важно:
- При загрузке файлов на GitHub не затирайте supabase-config.js, если там уже стоят рабочие URL и ключ Supabase.
- После обновления сайта откройте его с параметром ?v=30, чтобы браузер точно взял свежие файлы.
