Что изменено
============

Добавлена нормальная замена логотипа через админку.

Теперь можно загрузить PNG / JPG / WEBP / SVG, и сайт сам подберет фон под цвет краев изображения, чтобы логотип не выглядел как чужой квадрат.

Как пользоваться
================

1. Откройте сайт.
2. Войдите как админ.
3. Админка → Настройки сайта.
4. В блоке «Бренд и шапка» выберите PNG/JPG/WEBP/SVG логотип.
5. Нажмите «Загрузить и применить логотип».
6. Нажмите «Сохранить все настройки».
7. Обновите сайт.

Если фон подобрался не идеально, рядом есть ручной выбор цвета «Фон под логотип».

Supabase
========

Если свежий setup.sql уже выполнялся, можно выполнить только файл:
LOGO_ADAPTIVE_SUPABASE.sql

Он добавляет поля:
- site_logo_url
- site_logo_bg

Файлы логотипа грузятся в существующий bucket lesson-files, папка site/.

Важно
=====

При загрузке на GitHub не затирайте supabase-config.js, если в нем уже стоят рабочие URL и ключ Supabase.
