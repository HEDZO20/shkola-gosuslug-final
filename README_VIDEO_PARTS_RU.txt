# Видео больше 50 МБ: как теперь делать правильно

В браузере и на GitHub Pages нельзя надежно обрезать видео 500 МБ прямо на сайте. Поэтому сделан правильный бесплатный вариант:

1. Большое видео режется на компьютере через `VIDEO_CONVERTER.bat`.
2. Получаются MP4-части примерно до 50 МБ.
3. В админке можно выбрать сразу несколько частей.
4. Сайт загрузит их в Supabase и добавит в один урок.
5. Ученик смотрит все части на той же странице урока.

## Как пользоваться

1. Распакуй архив сайта.
2. Запусти `VIDEO_CONVERTER.bat`.
3. Выбери большое видео.
4. Дождись, пока появится папка `название_видео_parts_for_site`.
5. Открой сайт → Админка → Уроки → Редактировать урок.
6. В блоке видео выбери все MP4-части сразу.
7. Нажми `Загрузить выбранные видео`.
8. Нажми `Сохранить урок`.

## Важно

- Каждый файл должен быть меньше 50 МБ для Supabase Free.
- Если какая-то часть получилась больше 50 МБ, открой `VIDEO_CONVERTER.ps1` и замени `-maxrate 1100k` на `-maxrate 800k`, потом запусти заново.
- YouTube/Rutube/VK по ссылке всё равно остаются лучшим вариантом, когда видео не блокируется.

## Supabase

Выполни один раз файл:

`VIDEO_PARTS_SUPABASE.sql`

Он добавляет колонку `video_parts` для хранения нескольких частей видео в одном уроке.
