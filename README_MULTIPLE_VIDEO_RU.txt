ШКОЛА ГОСУСЛУГ — НЕСКОЛЬКО ВИДЕО В ОДНОМ УРОКЕ

Что добавлено:
1. В один урок можно добавить несколько видео.
2. Поддерживаются VK Видео, YouTube, Rutube, iframe-код VK и MP4-файлы до 50 МБ.
3. В админке появилось удобное поле «Несколько видео в одном уроке».
4. Каждое видео можно вставлять с новой строки:
   Введение | https://vkvideo.ru/video-123456_789012345
   Практика | https://youtu.be/xxxx
   Итог | https://rutube.ru/video/xxxx/
5. Можно вставить ссылку в поле «Одно основное видео» и нажать «+ Добавить эту ссылку в список видео».
6. Ученик видит все видео внутри одного урока.
7. Загруженные MP4-файлы также автоматически добавляются в список видео.

Как загрузить:
1. Загрузите файлы на GitHub поверх старых.
2. Не затирайте supabase-config.js.
3. Если поле video_parts уже добавлено в Supabase, SQL выполнять не нужно.
4. Если не добавлено, выполните VIDEO_PARTS_SUPABASE.sql один раз.

Лучший вариант для заказчика:
- Загружать большие видео в VK Видео от имени группы.
- Вставлять ссылки в поле «Несколько видео в одном уроке».
- Supabase оставить для учеников, уроков, тестов и прогресса.
