Школа Госуслуг — режим «одно видео из частей»

Что добавлено:
1. В один урок можно добавить несколько видео-частей до 50 МБ.
2. Сайт сам сортирует части по номеру в названии файла: part_001, part_002, Часть 01 и т.д.
3. На странице урока показывается общий прогресс просмотра всех частей.
4. После окончания одной MP4-части следующая часть запускается автоматически.
5. Когда ученик досмотрел все части, урок автоматически отмечает «Видео просмотрено».
6. В админке у каждого урока видно статус видео: нет видео / основное видео / несколько частей.

Как пользоваться:
1. Большое видео сначала прогоните через VIDEO_CONVERTER.bat.
2. Откройте админку сайта → Уроки → Редактировать.
3. В блоке видео выберите все созданные MP4-части сразу.
4. Нажмите «Загрузить выбранные видео».
5. Нажмите «Сохранить урок».
6. Ученик увидит один блок «Видео урока», а части будут идти по очереди.

Что выполнить в Supabase:
- Если вы уже выполняли VIDEO_PARTS_SUPABASE.sql или OPTIMIZE_SUPABASE.sql, заново выполнять необязательно.
- Если поле video_parts еще не добавлено, выполните VIDEO_PARTS_SUPABASE.sql.

Важно:
- supabase-config.js не затирайте, если там уже стоят ваши рабочие URL и ключ.
- На Supabase Free один файл должен быть до 50 МБ, поэтому части лучше делать 45–49 МБ.
