ИСПРАВЛЕНИЕ: регистрация без email-писем Supabase

Что изменено в сайте:
1. Убрана кнопка восстановления пароля через письмо, чтобы не ловить лимит Supabase.
2. Регистрация теперь не передает emailRedirectTo.
3. Если Supabase все равно пытается отправлять письмо, сайт показывает понятное сообщение.
4. Логика подтверждения учеников остается через админку: новый ученик ждет approval_status = pending, админ подтверждает вручную.

ВАЖНО:
Этот архив не может сам отключить Confirm email внутри Supabase, потому что это настройка проекта Supabase, а не файл сайта.

Что сделать один раз в Supabase:
Authentication → Providers → Email → Confirm email = OFF

После этого:
- ученик регистрируется без письма;
- Supabase не тратит email-лимит;
- ученик видит ожидание подтверждения;
- админ подтверждает ученика в админке.

Если ученик забыл пароль:
Supabase → Authentication → Users → выбрать пользователя → Reset password / Update password.
