ПОДДЕРЖКА VK ВИДЕО ДЛЯ УРОКОВ

Что добавлено:
1. В админке урока можно вставлять ссылку на VK Видео.
2. Можно вставлять готовый iframe-код VK Видео.
3. Сайт сам превращает ссылку VK в встроенный плеер.
4. Ученик смотрит видео прямо внутри урока.
5. YouTube, Rutube и загрузка MP4-частей остались.

Как пользоваться заказчику:
1. Создать группу ВК для школы / курса.
2. Загрузить видео в VK Видео от имени группы.
3. Настроить доступ к видео так, чтобы ученики могли его смотреть.
4. Скопировать ссылку на видео или код для вставки iframe.
5. Открыть сайт → Админка → Уроки → Редактировать.
6. Вставить ссылку в поле «Основная ссылка на видео».
7. Нажать «Сохранить урок».

Поддерживаемые варианты:
- https://vk.com/video-123456_789012345
- https://vkvideo.ru/video-123456_789012345
- ссылка VK с параметром z=video...
- готовый iframe-код вида <iframe src="https://vkvideo.ru/video_ext.php?...">

Важно:
- Если видео в VK закрыто настройками приватности, ученики могут увидеть ошибку или просьбу войти в VK.
- Если ВК заблокирует видео из-за авторских прав или правил площадки, сайт это обойти не сможет.
- Для больших видео это удобнее, чем Supabase Storage, потому что Supabase Free не принимает файлы больше 50 МБ.

Что загружать на GitHub:
- все файлы из архива поверх старых;
- supabase-config.js не затирать, если там уже твой рабочий URL и ключ.

Supabase менять не нужно.
